Detailed Description

The main entry point for the SaveIt JavaFX application.

This class extends the JavaFX Application class and is responsible for bootstrapping the user interface, loading the initial login view, setting the application icon, and configuring the primary stage.

void com.saveit.App.start ( Stage stage) throws Exception

Starts the primary stage and initializes the main scene.

This method loads the login FXML resource, sets up the application window properties (title, icon, and maximized state), and displays the stage to the user.
