Detailed Description

Facade class that orchestrates the various budget-related services.

The BudgetManager acts as the central point of contact for the UI layer, delegating specific tasks to specialized services like CycleManager, ExpenseService, and BudgetCalculator. It maintains the overall state of a user's financial tracking session.
