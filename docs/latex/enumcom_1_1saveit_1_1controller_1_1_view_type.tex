\doxysubsection{Detailed Description}
Enumeration defining the available views and their corresponding FXML file paths. 

This enum serves as a central registry for navigation within the application. Each constant maps a logical view name (e.\+g., DASHBOARD) to the physical resource location of its Java\+FX FXML layout file.
