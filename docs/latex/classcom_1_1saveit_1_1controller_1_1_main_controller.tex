\doxysubsection{Detailed Description}
\doxylink{classcom_1_1saveit_1_1controller_1_1_controller}{Controller} responsible for managing the main dashboard view. 

This class coordinates the display of high-\/level budget metrics, including remaining funds, daily limits, and cycle dates. It also manages the population of tables showing recent transactions and spending summarized by category.
