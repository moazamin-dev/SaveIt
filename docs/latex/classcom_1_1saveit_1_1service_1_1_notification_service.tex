\doxysubsection{Detailed Description}
Service responsible for delivering visual alerts and budget status updates. 

This class monitors the percentage of budget consumption and triggers Java\+FX-\/based desktop notifications to inform the user when specific thresholds (e.\+g., 70\% or 100\%) are reached.
