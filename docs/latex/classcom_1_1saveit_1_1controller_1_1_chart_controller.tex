\doxysubsection{Detailed Description}
\doxylink{classcom_1_1saveit_1_1controller_1_1_controller}{Controller} responsible for managing and displaying financial data visualizations. 

This class interacts with the \doxylink{classcom_1_1saveit_1_1service_1_1_report_generator}{Report\+Generator} to populate various Java\+FX charts, including a Pie\+Chart for categories, a Bar\+Chart for weekly trends, and a Line\+Chart for monthly spending analysis. It also manages summary statistics like total savings and budget usage percentage.
