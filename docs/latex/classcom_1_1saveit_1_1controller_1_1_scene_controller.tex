\doxysubsection{Detailed Description}
Singleton class responsible for managing scene transitions and controller lifecycle. 

The \doxylink{classcom_1_1saveit_1_1controller_1_1_scene_controller}{Scene\+Controller} handles the loading of FXML files, instantiation of controllers via a custom controller factory, and global event dispatching (such as user session updates) across all active controllers.
